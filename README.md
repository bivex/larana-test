# larana-test

Experimental playground. Where ideas are born and code meets creativity.

## Project Structure

| File | Description |
|------|-------------|
| `server.go` | Go HTTP server |
| `deploy.sh` | Deployment script |
| `serve.sh` | Local server startup script |

## Getting Started

```bash
# Start the local server
./serve.sh

# Deploy
./deploy.sh
```
